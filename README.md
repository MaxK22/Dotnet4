- AlgoTests - тесты для основного алгортма (1 задание)
- App - WPF приложение (1 + 2 задание)
- Contracts - классы для json запросов / контракты (2 задание)
- Controller - класс распределяющий задачи по серверам (2 задание)
- Controller.TestHost - простое приложение host решающее базовую задачу (4 города в квадрате) - работает с серверами из appsettings.json (2 задание)
- Core - класс генетического алгоритма (1 задание)
- Worker - сервер, который запускает Core
- Worker.Tests - тесты на работу сервера Worker (там в 3 пунтке 3 задания требуется)
- Worker.UniTests - тесты на работу сервисов сервера Worker
